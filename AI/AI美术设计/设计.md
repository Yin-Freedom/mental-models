# AI 生成部件

AI生成的奔跑太差了，修改方向为让AI生成角色的各个部位，然后人工使用spine制作骨骼动画。

绕开AI在时序、空间上的弱点，人工根据骨骼动画经验拼接部件。



```
生成一个用于脊椎骨骼动画的2D游戏角色PART SET。
[角色] 埃及风格的斑点猫，来自图1——风格相同，斑点一致。
[所需部件——分别在1024×768透明画布上绘制，然后裁剪至指定尺寸；接缝边缘用红色“+”标记]1. 身体            380×180   转动点：躯干中心2. 头部            220×200   转轴：颈部底座3. 耳左，耳右    70×110    转动点：耳根（底部）；右为左的镜像4. 前腿左/右，上部70×130，下部70×140，枢轴：肩部/肘部（顶部）5. 后腿左/右，上部100×160，下部90×170，枢轴：髋关节/膝盖（顶部）6. 尾部底边 120×140，尾部中间 110×130，尾部尖端 100×130  
枢轴：各段的上边缘
[规则]  
- 统一黑色轮廓2像素，50%灰色填充，绿色背景(#00FF00)，与图1相同的点阵图案（约40个点）。  
- 每条连接边缘添加8-16像素的主体风格重叠。  
- 所有部件朝向右侧，右侧部件为左侧部件的精确镜像（无需重新绘制）。  
- 输出：15张PNG文件，透明，无文字，无绿色背景，无水印。
```
